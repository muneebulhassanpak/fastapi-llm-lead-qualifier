# Security Policy

## Reporting a vulnerability

Please do not open a public issue for security problems.

Report them privately through [GitHub private vulnerability reporting](https://github.com/muneebulhassanpak/lead-qualification-api/security/advisories/new). Include steps to reproduce and the impact you expect.

You can expect an acknowledgement within a few days.

## Scope

This is a portfolio project. The public demo uses fake data only and a demo API key that is meant to be public. Reports about the demo key being visible are not vulnerabilities; reports about it reaching data outside the demo tenant are.
